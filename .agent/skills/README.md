# Skills for CV Website Optimization

This directory contains 10 specialized skills for optimizing and enhancing the CV website.

## Available Skills

### Performance & Core Web Vitals
- **web-performance-optimization** - Optimize loading speed, Core Web Vitals (LCP, FID, CLS), bundle size, and runtime performance

### Accessibility
- **accessibility-compliance-accessibility-audit** - Ensure WCAG compliance, screen reader compatibility, and inclusive design

### Analytics & Tracking
- **analytics-tracking** - Design and implement analytics tracking for downloads, page views, and user interactions

### SEO & Discoverability
- **seo-fundamentals** - Core SEO principles including E-E-A-T, technical foundations, and content quality
- **seo-meta-optimizer** - Create optimized meta titles, descriptions, and URL suggestions
- **schema-markup** - Add structured data (JSON-LD) for rich results and better search visibility

### Document Management
- **pdf-official** - PDF generation, manipulation, and optimization best practices

### Code Quality
- **frontend-dev-guidelines** - Modern frontend development standards for clean, maintainable code

### Design & User Experience
- **ui-ux-designer** - Professional UI/UX principles, design systems, and component libraries
- **mobile-design** - Mobile-first design patterns, touch interactions, and responsive layouts

## How to Use

Each skill directory contains a `SKILL.md` file with detailed guidance, examples, and best practices. Reference these when implementing the corresponding features in the implementation plan.
